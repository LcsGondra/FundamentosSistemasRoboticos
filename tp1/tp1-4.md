# Exercício 4: Criação do Ambiente de Desenvolvimento ROS 2 no WSL2 (Ubuntu 22.04)

---

## 1. Análise do Tutorial do Professor vs. Requisitos do TP1

O tutorial disponibilizado pelo professor ([`setup-ros2-humble-wsl2.md`](https://github.com/Prof-Dacio-INFNET/PBRoboticos_prof_dacio/blob/main/tutoriais/setup-ros2-humble-wsl2.md)) **faz total sentido e é altamente recomendável**, pois antecipa e previne as principais armadilhas de ambiente encontradas pelos alunos:

1. **Trava de Segurança de Versão do Ubuntu (`jammy`):** O ROS 2 Humble funciona estritamente no Ubuntu 22.04 (`jammy`). Se o WSL instalar outra versão (ex: 24.04 ou 26.04), a instalação do ROS falhará.
2. **Inclusão do `rosdep`:** Instalação e inicialização do `rosdep` (`sudo rosdep init && rosdep update`), essencial para resolver dependências de pacotes em TPs futuros.
3. **Isolamento de Rede (`ROS_DOMAIN_ID`):** Define uma ID de domínio única para evitar a interferência de tópicos entre alunos conectados à mesma rede Wi-Fi da faculdade.
4. **Reinício do WSLg (`wsl --shutdown`):** Resolve problemas de interface gráfica e servidor X/WSLg que ocorrem após grandes instalações do APT.

## 2. Passo a Passo Completo Integrado (Professor + Requisitos do TP1)

### Passo 1 — Instalação do WSL2 com Ubuntu 22.04 Dedicado (No PowerShell como Administrador)

```powershell
# 1. Instalar a distribuição Ubuntu 22.04 explicitamente
wsl --install -d Ubuntu-22.04

# 2. Atualizar o WSL e verificar a versão (deve ser WSL 2)
wsl --update
wsl --list --verbose

# 3. Definir o Ubuntu-22.04 como distribuição padrão e abrir
wsl --set-default Ubuntu-22.04
wsl -d Ubuntu-22.04
```

---

### Passo 1.5 — Confirmação Obrigatória da Versão do Ubuntu

Dentro do terminal do Ubuntu recém-aberto:

```bash
lsb_release -a
```
> **Confirmação:** Deve exibir obrigatoriamente `Ubuntu 22.04.x LTS (jammy)`.

---

### Passo 2 — Preparar o Ubuntu e Dependências

```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y locales curl gnupg software-properties-common
sudo locale-gen pt_BR.UTF-8 en_US.UTF-8
```

---

### Passo 3 — Trava de Validação e Instalação do ROS 2 Humble

```bash
# 1. Trava de verificação de versão (Script do Professor)
source /etc/os-release
[ "$UBUNTU_CODENAME" = "jammy" ] && echo "OK: Ubuntu 22.04 (jammy) — pode seguir" \
  || echo "PARE: este Ubuntu é '$UBUNTU_CODENAME'. O Humble exige 22.04 (jammy)."

# 2. Habilitar repositório universe e adicionar chave GPG
sudo add-apt-repository universe -y
sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key \
  -o /usr/share/keyrings/ros-archive-keyring.gpg

# 3. Adicionar repositório do ROS 2 Jammy
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] http://packages.ros.org/ros2/ubuntu jammy main" | sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null

# 4. Instalar ROS 2 Humble Desktop, Colcon e Rosdep
sudo apt update
sudo apt install -y ros-humble-desktop ros-dev-tools python3-colcon-common-extensions python3-rosdep

# 5. Inicializar o rosdep
sudo rosdep init && rosdep update
```

---

### Passo 4 — Configuração do Ambiente e `ROS_DOMAIN_ID`

```bash
# Adicionar o source do ROS 2 e a ID de domínio única ao ~/.bashrc
echo "source /opt/ros/humble/setup.bash" >> ~/.bashrc
echo "export ROS_DOMAIN_ID=42" >> ~/.bashrc    # Escolha um número único entre 1 e 101
source ~/.bashrc
```

---

### Passo 5 — Reiniciar o WSL (Correção do WSLg)

No **PowerShell**:
```powershell
wsl --shutdown
wsl -d Ubuntu-22.04
```

## 3. Criação e Compilação do Workspace `tp1_ws` (Exigência do TP1)

No terminal do Ubuntu:

```bash
# 1. Criar a pasta do workspace e subpasta src/
mkdir -p ~/tp1_ws/src
cd ~/tp1_ws

# 2. Executar a compilação inicial com Colcon
colcon build

# 3. Carregar o arquivo de overlay local
source install/setup.bash
```

### Estrutura de Diretórios Gerada (`tree tp1_ws/`):

```bash
sudo apt install -y tree
tree -L 2 ~/tp1_ws/
```
