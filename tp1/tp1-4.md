# Exercício 4: Criação do Ambiente de Desenvolvimento ROS 2

---

## 1. Procedimento Passo a Passo de Instalação do ROS 2 Humble

**Validação da Versão do Sistema Operacional:**
```bash
lsb_release -a
```
Confirmação: Ubuntu 22.04 LTS Jammy.

**Configuração do Locale UTF-8:**
```bash
sudo apt update && sudo apt install -y locales
sudo locale-gen en_US en_US.UTF-8
sudo update-locale LC_ALL=en_US.UTF-8 LANG=en_US.UTF-8
export LANG=en_US.UTF-8
```

**Habilitação do Repositório Universe e Chave GPG:**
```bash
sudo apt install -y software-properties-common
sudo add-apt-repository universe
sudo apt update && sudo apt install -y curl gnupg lsb-release
sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key -o /usr/share/keyrings/ros-archive-keyring.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] http://packages.ros.org/ros2/ubuntu $(lsb_release -cs) main" | sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null
```

**Instalação do ROS 2 Humble Desktop e Ferramentas de Build:**
```bash
sudo apt update
sudo apt install -y ros-humble-desktop python3-colcon-common-extensions python3-rosdep
```

**Inicialização do Rosdep e Configuração do Shell:**
```bash
sudo rosdep init
rosdep update
echo "source /opt/ros/humble/setup.bash" >> ~/.bashrc
echo "export ROS_DOMAIN_ID=42" >> ~/.bashrc
source ~/.bashrc
```

---

## 2. Criação do Workspace e Build Inicial com Colcon

**Criação da Estrutura de Diretórios:**
```bash
mkdir -p ~/tp1_ws/src
cd ~/tp1_ws
colcon build
```

**Configuração do Source do Workspace:**
```bash
echo "source ~/tp1_ws/install/setup.bash" >> ~/.bashrc
source ~/.bashrc
```

**Estrutura Gerada:**
```text
tp1_ws/
├── build/
├── install/
├── log/
└── src/
```

**Saída Esperada do Build Vazio:**
```text
Summary: 0 packages finished
```

---

## 3. Validação do Ambiente e Testes de Referência

**Diagnóstico do Sistema:**
```bash
ros2 doctor
```
Saída esperada: Verificação finalizada com status OK sem erros bloqueantes.

**Execução dos Nós de Demonstração:**

Terminal 1:
```bash
ros2 run demo_nodes_py talker
```
Saída no terminal do publisher:
```text
[INFO] [talker]: Publishing: 'Hello World: 1'
[INFO] [talker]: Publishing: 'Hello World: 2'
```

Terminal 2:
```bash
ros2 run demo_nodes_py listener
```
Saída no terminal do subscriber:
```text
[INFO] [listener]: I heard: [Hello World: 1]
[INFO] [listener]: I heard: [Hello World: 2]
```
