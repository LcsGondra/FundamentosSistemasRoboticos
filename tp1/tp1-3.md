# Exercício 3: Sensores e Atuadores em Sistemas Robóticos

---

## 1. Mapeamento de Componentes de Hardware

| Componente | Sensor ou Atuador | Tipo de Dado | Aplicação |
| :--- | :--- | :--- | :--- |
| **LiDAR 2D** | Sensor | Contínuo | Mapeamento 2D de ambientes e desvio de obstáculos em robôs móveis autônomos. |
| **IMU** | Sensor | Contínuo | Estimativa de orientação e aceleração 3D para fusão de dados de odometria. |
| **Câmera RGB** | Sensor | Contínuo | Reconhecimento de objetos e rastreamento visual de alvos em tempo real. |
| **Motor DC com encoder** | Atuador e Sensor | Discreto e Contínuo | Tração diferencial de rodas com realimentação de pulsos em malha fechada. |
| **Servo motor** | Atuador | Discreto | Controle de ângulo de esterço de direção e articulações de garras. |
| **Sensor ultrassônico** | Sensor | Discreto | Detecção de obstáculos de curto alcance e barreiras de proteção. |

---

## 2. Fluxo de Dados do Sistema Robótico Móvel

```text
+-----------------------------------------------------------------------------------+
|                        FLUXO DE DADOS DO SISTEMA ROBÓTICO                         |
+-----------------------------------------------------------------------------------+
|                                                                                   |
|  [LiDAR 2D] ========> (sensor -> processamento) ========> [Unidade de             |
|  [Câmera RGB-D] =====> (sensor -> processamento) ========>  Processamento Central]|
|                                                                    ||             |
|                                                                    ||             |
|  [Motor de Tração] <== (processamento -> atuador) =================||             |
|  [Servo de Direção] <= (processamento -> atuador) =================+|             |
|                                                                                   |
+-----------------------------------------------------------------------------------+
```

**Descrição do Fluxo de Informações:**

1. **LiDAR 2D para Unidade de Processamento Central:** 
Fluxo na direção de sensor para processamento. Envia o fluxo contínuo de varredura angular e distâncias a laser para os nós de mapeamento e desvio de obstáculos.

2. **Câmera RGB-D para Unidade de Processamento Central:** 
Fluxo na direção de sensor para processamento. Transmite o fluxo contínuo de quadros de imagem e matrizes de profundidade 3D para os nós de percepção e identificação de objetos.

3. **Unidade de Processamento Central para Motor de Tração:** 
Fluxo na direção de processamento para atuador. Envia sinais de modulação por largura de pulso ou comandos de velocidade para o driver do motor, alterando a rotação das rodas motrizes.

4. **Unidade de Processamento Central para Servo de Direção:** 
Fluxo na direção de processamento para atuador. Envia pulsos de comando de posição angular para o servo motor, ajustando o ângulo de esterço das rodas direcionais.
